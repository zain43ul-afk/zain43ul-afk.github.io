## Publishing

The site is designed for GitHub Pages and consists of static HTML, CSS, and JavaScript. Portfolio samples open from their owner-managed Google Sheets and Google Docs links. The native project slider lives directly in the main `index.html`, `styles.css`, and `script.js`; the generated `zain43ul-frontenddemo.github.io/` directory supplies only the 12 interactive demo experiences shown inside that same pop-up. Keep this directory and the root `.nojekyll` file when uploading to GitHub.
