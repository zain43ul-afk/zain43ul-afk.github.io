## Google Sheets sharing before publishing

For every linked workbook, set **General access** to **Anyone with the link — Viewer**. Do not use public **Editor** access; it allows visitors to alter the portfolio samples.

## Publishing

The site is designed for GitHub Pages and consists of static HTML, CSS, and JavaScript. Spreadsheet samples open from their owner-managed Google Sheets links. The native spreadsheet, research, and frontend sliders live directly in the main `index.html`, `styles.css`, and `script.js`; the generated `zain43ul-frontenddemo.github.io/` directory supplies only the 12 interactive frontend demo experiences shown inside the frontend pop-up. Keep this directory and the root `.nojekyll` file when uploading to GitHub.
